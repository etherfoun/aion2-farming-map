# AION 2 Altgard — Spot Farm Optimizer

Интерактивная карта и оптимизатор спотов фарма питомцев для региона Altgard в AION 2.

**Live Demo:** [https://etherfoun.github.io/aion2-farming-map/](https://etherfoun.github.io/aion2-farming-map/)

## Возможности

- **Кластеризация спотов в реальном времени:** Быстрый пространственный алгоритм кластеризации с Non-Maximum Suppression (NMS) для поиска самых плотных зон спавна.
- **Поддержка локализации RU / EN:** Мгновенное переключение языка интерфейса, названий локаций и видов питомцев.
- **Фильтрация по жанрам питомцев:** Cogni, Fera, Natura, Varian, а также поиск мульти-спотов (несколько видов в одном радиусе).
- **Выбор и исключение питомцев:** Возможность выбора конкретных видов питомцев или скрытия уже собранных точек/видов из расчёта.
- **Кастомная проекция Leaflet CRS:** Использование оригинальной координатной сетки и тайлов карты Altgard.
- **Интерактивные маркеры и полигоны:** Подробные карточки спотов с составом мобов, координатами и функцией быстрого копирования.

## Стек технологий

- HTML5 / CSS3 / JavaScript (Vanilla ES6+)
- [Leaflet.js](https://leafletjs.com/) (с кастомным `L.CRS.Simple`)
